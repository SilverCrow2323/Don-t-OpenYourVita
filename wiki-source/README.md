# Wiki source and publishing

The `wiki-source/` directory is the tracked source for the practical GitHub Wiki.

## Page rules

- One topic per page.
- Start with a short explanation and one concept per bullet.
- Use **MUST KNOW!!** only for required prerequisites or important safety/compatibility notes.
- Use **Optional** only for non-essential enhancements.
- Leave basic steps unlabelled.
- Keep the port package and the original game's data clearly separate.
- Never publish copyrighted game files or private user data.

## First-time Wiki activation

1. Open the [GitHub Wiki](https://github.com/SilverCrow2323/Don-t-OpenYourVita/wiki).
2. Create and save a first page titled **Home**.
3. From a clone with Git credentials, run `sh tools/publish_wiki.sh`.

Edit the Markdown in `wiki-source/`, not only the live Wiki.
