# FAQ

## Does the repository include the original game?

No. The port's VPK and the original PC game's content are separate. Obtain the original game from the creator's [itch.io page](https://via01.itch.io/dont-open-your-eyes).

## Where do I copy the game folder?

Copy the original `game/` folder to `ux0:app/RNPYDNOPE/game/`.

## Can I rename the title-ID folder?

No. Use the documented title ID `RNPYDNOPE`.

## Which tool was used to create the port?

The README credits the [Ren'Py PSVita Distribution Tool v1.0](https://github.com/SonicMastr/renpy-vita/releases/tag/v1.0).

## Where should I report a problem?

Open an issue in the [port repository](https://github.com/SilverCrow2323/Don-t-OpenYourVita/issues) and include the port version, install path and reproducible steps. Do not upload the original game files.
