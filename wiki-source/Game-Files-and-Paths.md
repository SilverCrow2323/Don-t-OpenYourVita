# Game files and paths

The Vita port and the original game content are separate pieces. The VPK installs the Vita application; the original PC game's `game/` folder supplies the visual novel content.

## Required layout

The README documents this destination:

```
ux0:app/RNPYDNOPE/game/
```

- Keep the directory name exactly `RNPYDNOPE`.
- Copy the original `game/` folder into the application directory.
- Do not copy the folder beside the title-ID directory.
- Do not rename or flatten the contents of `game/` unless the port instructions explicitly require it.

## Obtain the original content

Download the original game from the [creator's itch.io page](https://via01.itch.io/dont-open-your-eyes).

> **MUST KNOW!!** Do not share or redistribute the original game's proprietary files in public issues, repository commits or Wiki attachments. Share technical logs and path information instead.
