# (Don't) Open Your Eyes — Vita guide

This repository contains the PlayStation Vita Ren'Py port of **(Don't) Open Your Eyes**, a short horror visual novel. The repository provides the Vita port; the original game's content files are obtained separately from the creator.

> [!IMPORTANT]
> **MUST KNOW!!** The VPK and the original PC game's `game/` folder are separate. Obtain the original game from the [creator's itch.io page](https://via01.itch.io/dont-open-your-eyes); do not expect the repository source to contain the copyrighted game data.
